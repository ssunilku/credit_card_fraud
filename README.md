### Credit Card Fraud Detection Using Machine Learning

Developed a machine learning model to identify fraudulent credit card transactions using **Logistic Regression**. The project involves exploratory data analysis, handling missing values, analyzing class imbalance, and applying undersampling to balance legitimate and fraudulent transactions. The dataset is split into training and testing sets to train the model and evaluate its performance using accuracy scores. The model achieved **95.74% training accuracy and 89.80% testing accuracy**, demonstrating the potential of machine learning in detecting suspicious financial transactions and supporting fraud prevention systems.

**Technologies Used:** Python, Pandas, NumPy, Scikit-learn, Logistic Regression, Exploratory Data Analysis (EDA).
